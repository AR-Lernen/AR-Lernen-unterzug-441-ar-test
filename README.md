# Unterzug Pos. 441 – Vor-Ort-Test

Testseite für die Ausrichtung des 1:1-Bewehrungsmodells am Bauwerk (WebXR, Chrome auf Android).
Ganzer Träger oder Ausschnitt, Stütze wählen (Link-Anker `#17`, `#15`, `#13`, `#g12`, Ausschnitt mit `-aus`).
Ganzer Träger: Ausrichtung über je einen Punkt an zwei Stützen. Ausschnitt: Seite des Stützenfußes wählen,
„In AR ausrichten“, linke und rechte untere Ecke antippen, dann fein nachstellen.

Veröffentlichung über GitHub Pages (*Settings → Pages → Source: GitHub Actions*).

`ansicht.html`: normale Ansicht mit allen Maßstäben zum Testen neuer Funktionen
(zurzeit: Schalter „Fertigteilträger“, Link-Anker `#ft`).
